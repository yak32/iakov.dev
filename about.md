# About

I'm Iakov Sumygin, a software engineer living in London. My day job has been in large products: Amazon Prime Video on PlayStation and Apple TV at Amazon, and graphics work on World of Tanks at Wargaming/BigWorld before that.

Outside work I build my own C++ game engine, Glow, and games on top of it. The engine has run on Windows, Android, the web (Native Client, then Emscripten and WebAssembly) and DirectX 11 / OpenGL. The best known game made with it is Iron Cube, a multiplayer tank game in a destructible voxel world that went out on Google Play. Along the way it took first place for Best Game Optimized for Intel Graphics at Intel Level Up 2009, and first prize in the Intel Perceptual Computing Challenge in 2013.

This blog started on Blogger in 2009, moved to WordPress, then to glow3d.com/blog, and now lives here. The older posts have been tidied up, but the dates, pictures and videos are the originals.

Some of the code is open source:

- [glw_imgui](https://github.com/yak32/glw_imgui), a small code-driven immediate-mode GUI
- [glw_json](https://github.com/yak32/glw_json), a single-header JSON serialiser that doesn't allocate while parsing
- [glw_profiler](https://github.com/yak32/glw_profiler), a minimal C++ profiler
