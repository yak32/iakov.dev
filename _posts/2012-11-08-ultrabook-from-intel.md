I'm taking part in **[The Windows 8* & Ultrabook™ App Innovation Contest](http://www.codeproject.com/Competitions/598/The-Windows-8-Ultrabook-App-Innovation-Contest.aspx)**, and after I passed to Round 2 Intel sent me a laptop for free. It's a brand new Ultrabook on Ivy Bridge with a dual-core CPU with hyper-threading, a 240 GB SSD, a touch screen, a multi-touch touchpad, a compass, an accelerometer and an ambient light sensor. It's a pre-release reference device and Intel has some disclosure conditions, so I can't write much about it (and I'm too lazy to write a lot anyway).

It runs 64-bit Windows 8. Working in Windows 8 is weird but strangely convenient, half PC and half tablet. The new interface is minimalistic, in line with Microsoft's new design rules.

It weighs only 3 pounds, so it will be easy to take with me when I travel. There is more about this device [here](http://www.hanselman.com/blog/InitialImpressionsOfThe3rdGenerationIvyBridgeIntelUltrabookReferenceHardwareForDevelopersOnWindows8.aspx).
