I've finally made the Glow engine cross-platform. The first platform after Windows is Google Native Client (NaCl), a technology that runs native C/C++ code inside a browser window. The screenshot shows the Tarta voxel terrain rendering in Chrome from a local test page, with a console full of GL errors that I still have to clean up.

What I like most is that a game can start straight from a link. There are no installation steps, and it reaches users on Windows, Linux and Mac OS. I'll write about the port in more detail later.
