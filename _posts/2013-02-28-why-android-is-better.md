This is my phablet, a Samsung Galaxy Note 2, running Launcher 8. It's a custom launcher that copies the Windows Phone home screen: square and wide tiles for the phone, settings, Dropbox, Skype, maps, the camera and a big clock with the date.

That photo is my whole argument. On Android the home screen is just another app, so if I like the look of Windows Phone tiles I can install a launcher and have them on a Samsung phone. Underneath it is still the same Android device with the same apps, and if I get bored of tiles I can switch back.
