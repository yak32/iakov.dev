A while ago I worked with [Sir carma](https://twitter.com/sir_carma?lang=en), an excellent voxel artist. This screenshot is from that project. The art is his, and the rendering is done by my Glow3D engine.

The project was a voxel game prototype, an isometric adventure in the spirit of the original Zelda. To get his models into the game I wrote a parser for the MagicaVoxel file format and reused a lot of the voxel code from Iron Cube. For the lighting I added NVIDIA HBAO+ for ambient occlusion and NVIDIA's shadow library.
