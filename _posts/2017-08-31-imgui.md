Version 0.1 adds initial support for themes and builds on Linux, macOS and Windows. The code is on GitHub: [https://github.com/yak32/glw_imgui](https://github.com/yak32/glw_imgui)

IMGUI (immediate-mode GUI) is a simple, code-driven GUI approach with no bloat, and many modern game engines and games use it. The best explanation of the idea is [this video](https://www.youtube.com/watch?v=Z1qyvQsjK5Y). The library has basic support for layout (attachable toolbars and layout serialisation), themes (colours and serialisation) and lock-free multithreading through triple buffering.

It started as part of my game engine. Some time ago I pulled it out into its own library and put it on GitHub.
