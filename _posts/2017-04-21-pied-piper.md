"Pied Piper" is a silly little game about dancing zombies. It's my first attempt to take part in Ludum Dare and actually finish a game.

**What went right.** Using Fuse for the characters and mixamo.com for the animations saved a lot of time. Fuse makes it easy to build a realistic character, and before the jam started I had already set up a pipeline for exporting characters from mixamo.com into my engine. Making the game was also a lot of fun. I laughed out loud for the first 10 minutes after I saw [the first dance](https://www.youtube.com/watch?v=CERzkDsdcv8), and that fun was a big part of why I kept going to the end.

**What went wrong.** Planning, as usual. I spent one whole evening picking music on freesound.org, which left me one evening and one night to write the code. As usual I also ran into several weird glitches, which is the downside of using my own engine. One of them made it into the first release for LD. It's fixed in the latest version.

Since this was my first LD, the only goal was to finish something. The engine is mature now and I can use it for the next LD. I'll probably keep working on Pied Piper if the community likes it.
