Some progress with the editor. It can now load and save projects, show a list of assets and a list of entities, and edit object properties. All of it runs in the in-game 3D UI, and all of it supports undo and redo.

That 3D UI is the immediate-mode interface scripted in Lua that I started on in August. The screenshot shows a few house models in a test scene with the entity list, the asset list and the property panel.
